# Meeral Group Training Website

This package contains a responsive static website prototype matching the approved visual direction.

## Pages
- `index.html` — Homepage
- `courses.html` — Searchable/filterable course catalog
- `course-detail.html` — Course detail page
- `styles.css` — Shared styling
- `script.js` — Menu, catalog filtering, tabs and registration modal

## Before launch
Replace the placeholder phone number, Riyadh address, statistics, prices, dates, course accreditation claims and stock photography with Meeral Group's confirmed business information.

The registration form is currently a front-end prototype. Connect it to your preferred backend, email service, CRM, WordPress form plugin, or API before production.

## Deploy
Upload all files to the public web root for `meeralgroup.com`, or use them as a design reference for a WordPress/Webflow/Next.js build.
